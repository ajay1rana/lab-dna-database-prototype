Laboratory DNA database prototype - application
Requires Python 3.9+ and openpyxl (numpy optional, for permutation tests).
Run:  python dna_import_app.py            (graphical interface)
      python dna_import_app.py --help     (command-line options)
Create a new empty SQLite database from the app (SQLite tab). Use synthetic or de-identified data only.
Prototype for research and local management; not validated for casework reporting.
